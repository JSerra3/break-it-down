# BREAK IT DOWN

Multiplication goggles. Type an expression and take it apart one layer per press: powers into copies of their base, whole numbers into primes, negative exponents flipped across the fraction bar. It never simplifies — the point is to see what is really there.

Open: https://jserra3.github.io/break-it-down/

Set a problem with a link: https://jserra3.github.io/break-it-down/?expr=%28x%5E5%2Fy%5E7%29%5E-3

The expression box types like Desmos: ^ for a power, / for a fraction, → or Space to step out.

Keys: Space / ↓ = break it down · ↑ = back

Built from the elm-obs BREAK IT DOWN source by `tools/build-breakdown.mjs`.
